# LinkCatch

Windows 10/11 64비트 미디어 다운로드·변환 앱입니다.

## 파일 하나로 실행

[LinkCatch.exe 다운로드](https://github.com/promise0627/linkcatch-updates/releases/latest/download/LinkCatch.exe)

받은 EXE 하나를 원하는 폴더에 두고 실행하세요. 별도 설치 프로그램과 Python 설치가 필요 없습니다.
[ZIP으로 받기](https://github.com/promise0627/linkcatch-updates/releases/latest/download/LinkCatch-win64.zip)도 가능합니다. ZIP에는 같은 EXE 하나만 들어 있습니다.

첫 실행에 필요한 다운로드·변환 도구는 앱이 공식 배포처에서 내려받고 SHA256을 확인합니다. 인터넷 연결이 필요합니다. 도구와 설정은 `%LOCALAPPDATA%\LinkCatch`에서 관리합니다. 여러 폴더에 둔 앱은 같은 도구를 공유하며, 성공한 도구 다운로드 캐시는 정리합니다.

라이선스와 출처는 앱의 **라이선스** 버튼에서 확인할 수 있습니다.

## 기존 사용자 업데이트

- **1.2.0 이상** 사용자는 **앱 업데이트** 버튼으로 받습니다.
- **1.0 / 1.1** 사용자는 새 EXE를 사용하거나 [최초 연결 패치](https://github.com/promise0627/linkcatch-updates/releases/download/v1.3.0/LinkCatch-1.3.0-bootstrap.zip)를 압축 해제하고 앱 종료 후 `apply-update.cmd`에서 기존 앱 폴더를 지정합니다.
- **엔진 갱신** 버튼은 공식 배포처의 yt-dlp를 갱신합니다.

이전 폴더의 파일은 남아 있을 수 있습니다. 새 폴더에서 파일 하나로 사용하려면 최신 EXE를 받으세요.

[릴리스 및 SHA256 체크섬](https://github.com/promise0627/linkcatch-updates/releases/latest)

본인이 다운로드·변환할 권한이 있는 미디어에 사용하세요. 로그인·DRM·라이브는 지원하지 않습니다.

이 저장소에는 배포 파일과 안내를 보관합니다.
