# LinkCatch

광고 없는 Windows 10/11 64비트 미디어 도구입니다.

## 설치 없이 바로 실행

1. [최신 바로 실행 ZIP 다운로드](https://github.com/promise0627/linkcatch-updates/releases/latest/download/LinkCatch-win64.zip)
2. ZIP 전체를 압축 해제하고 `LinkCatch` 폴더의 **LinkCatch.exe**를 실행합니다.
3. 첫 실행에 필요한 도구는 앱이 자동으로 준비합니다. 처음 한 번 인터넷 연결이 필요합니다.

**Install.cmd나 별도 설치 프로그램, Python 설치가 필요하지 않습니다.**
준비 중에는 앱에 진행 상황이 표시되며, 다음 실행부터는 기존 도구를 그대로 사용합니다.
`LinkCatch.exe`와 `_internal`, `tools`, `licenses` 폴더를 함께 보관하세요.

## 기존 사용자 업데이트

- **1.2.0 이상:** 앱의 **앱 업데이트** 버튼으로 최신 버전을 받습니다.
- **1.0 / 1.1:** [최초 연결 패치](https://github.com/promise0627/linkcatch-updates/releases/download/v1.2.1/LinkCatch-1.2.1-bootstrap.zip)를 압축 해제하고 앱 종료 후 `apply-update.cmd`를 실행하여 기존 앱 폴더를 지정합니다. 또는 새 바로 실행 ZIP을 사용합니다.
- **엔진 갱신:** 공식 배포처의 yt-dlp만 갱신합니다.

[배포 버전과 SHA256 체크섬](https://github.com/promise0627/linkcatch-updates/releases/latest)

앱 업데이트는 변경 파일 다운로드 → SHA256 검증 → 교체 → 재시작 순으로 적용됩니다.
다운로드·변환 도구는 공식 배포처에서 직접 받으며, 제공 ZIP에는 해당 GPL 도구 실행 파일을 포함하지 않습니다.
라이선스와 출처는 ZIP의 `licenses` 및 `THIRD_PARTY_NOTICES.txt`를 확인하세요.

본인이 다운로드·변환할 권한이 있는 미디어에 사용하세요. 로그인·DRM·라이브는 지원하지 않습니다.

이 저장소에는 배포 파일과 안내만 보관합니다.
